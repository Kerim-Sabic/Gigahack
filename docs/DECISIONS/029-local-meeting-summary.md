# 029 — Local LLM meeting summary in Minutes

The Minutes tab now has Generate summary / Regenerate summary and source navigation. A writer can queue a summary from all saved meeting transcript segments without ASR, diarization, action extraction, delivery or auto-approval. The existing supervisor, exclusive GPU admission, prepared local LLM and process cleanup are reused. No dependency or model was added.

Bounded rolling summarization reads every nonempty source turn, splits oversized utterances, checks rendered context, retains a compact prior summary, rejects truncated output and unknown citation IDs, and checkpoints individual groups. Output language follows the meeting's configured language. Developer response budget is llm.summary_tokens. This is an abstractive AI draft: citations validate source identity, not semantic correctness; a reviewer must check wording and important details. Rolling compression can omit minor details in long meetings.

Migration 008 stores versioned summary bodies, source fingerprints and job provenance. Membership and writer permissions protect endpoints. Source text/revisions and meeting context are checked before and after inference. Changes mark an old draft stale; stale drafts cannot enter new snapshots. Current drafts enter the immutable minutes body and HTML/PDF/JSON exports. Regeneration increments the meeting revision, invalidating approval of older snapshots for current delivery; historical exports remain unchanged. No reviewed action items are modified. Existing approval and internal mail routing are preserved.

Validation: 251 backend tests passed, two platform skips; 30 frontend tests passed; Ruff and production build passed. Tests include authorization, stale sources, concurrent edits, unknown citations, export persistence, oversized text, final-turn coverage, checkpoint reuse and truncation rejection. Real local inference ran on an explicitly synthetic Romanian transcript; results preserved proposal/unconfirmed-date language with room for editorial improvement. Desktop and mobile browser checks covered generation, completion, source navigation and overflow. The temporary meeting was removed; private proof remains in .runtime. This is not a general summary-accuracy qualification. Changes remain local as explicitly requested.
